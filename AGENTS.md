# Agent instructions

This is a public-distribution repository: never commit drafts, paid packages, private creator information, secrets or confidential documentation. Publish only approved free content. Changes must preserve existing asset paths and packages, and private source material must stay in its private repository.

Before a commit, run `tools/validate.sh`; before a release, also validate the generated manifest using the iOS app's private validator as described in README. The iOS repository is read-only for this project. Do not claim a deployment, licence grant or device test that has not occurred. Protect main and the Pages environment and use pinned actions.
