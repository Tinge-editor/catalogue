# Experimental research looks (not a release)

`catalogue.json` is an **experimental, unapproved** v1 manifest of 26 research looks for evaluation in development builds of Tinge (Manage Looks → Discover Looks → ⋯ → Connect Catalogue URL). It is not part of the production catalogue, is not built by `tools/build.py`, is not deployed to GitHub Pages, and does not change `catalogue/source.json`. The looks are not licensed for redistribution.

Do not merge this branch into `main`. Source, tooling and research notes live in the private iOS repository.
